# 단어 데이터 (2음절 명사)

## 파일

- `words-common-2syl.json` — **일상 어휘 2,185개**. 스탠다드 퍼즐 출제(정답 트리 생성)에 1순위로 쓰는 풀.
- `words-all-2syl.json` — **표준국어대사전 전체 2음절 명사 75,333개**. 다른 두 풀만으로 트리를 못 찾을 때
  최종 보조 풀, 그리고 "이 조합이 사전에 실제로 있는 단어인가"를 검증하는 용도. 사어·고어·전문용어까지
  전부 포함돼 있어 그대로 퍼즐에 쓰기엔 단어가 너무 낯설다(그래서 익스텐디드는 이 파일을 직접 쓰지 않음).
- `words-extended-2syl.json` — **익스텐디드 모드용 2음절 명사 14,666개**. `words-all-2syl.json`(사전 전체)을
  국립국어원 실사용 빈도 조사로 걸러 "사전에만 있는 단어"가 아니라 "실제 글에 한 번이라도 등장한 단어"만
  남긴 풀 — 스탠다드(2,185개)보다 훨씬 넓으면서도 사어투성이인 전체 사전보다는 훨씬 정제돼 있다.
  익스텐디드 퍼즐 출제 1순위이고, 그래도 모자라면 `words-all-2syl.json`으로 확장한다.

세 파일 모두 `["가게", "가격", ...]` 형태의 단순 문자열 배열(오름차순 정렬, 중복 없음)이다.

## 출처 · 저작권

### `words-common-2syl.json`, `words-all-2syl.json`

[han-dle/pd-korean-noun-list-for-wordles](https://github.com/han-dle/pd-korean-noun-list-for-wordles)
(**CC0-1.0**, 저작권 없음 — 자유롭게 가공·재배포 가능). 2026-09-12 시점의 `main` 브랜치에서 받음.

그 저장소의 원 출처는 국립국어원:
- `CommonNouns` ← [한국어 학습용 어휘 목록](https://www.korean.go.kr/front/etcData/etcDataView.do?mn_id=46&etc_seq=70&pageIndex=44) (2019-05-30 수정본)
- `AllNouns` ← 표준국어대사전 명사 (2018-11-13 수집)

### `words-extended-2syl.json`

국립국어원 [현대 국어 사용 빈도 조사](https://www.korean.go.kr/front/etcData/etcDataView.do?mn_id=46&etc_seq=61&pageIndex=44)
(2002, 교재·신문·잡지·대본·구어 등 약 900만 어절 말뭉치 기반. **공공누리 제1유형** — 출처표시 조건으로
자유 이용 가능). 배포 ZIP 안 `단어_빈도색인.txt`(품사별 등장 빈도 색인, CP949 인코딩)를 가공:

1. 품사가 `명`(명사)인 표제어만 남김.
2. 표제어 끝의 동형이의어 번호(`것01` → `것`)를 떼고, `^[가-힣]{2}$`(정확히 2글자 순한글)만 남김 —
   같은 글자로 합쳐지는 동형이의어는 빈도를 합산.
3. 그렇게 나온 15,044개 중 `words-all-2syl.json`(표준국어대사전 2음절 명사)에도 실제로 존재하는
   14,666개만 최종 채택 — 나머지 378개는 수사(첫째/둘째 등)·외래어·옛 표기 오차 등으로 사전 명사
   목록과 안 맞아 제외.

## 필터 규칙

`^[가-힣]{2}$`에 맞는 것만(정확히 2글자, 순한글) 남김 — 노드 하나가 음절 한 글자이므로, 부모+자식
두 글자가 합쳐졌을 때 유효한 "2음절 단어"인지만 확인하면 되기 때문. `words-common-2syl.json`/
`words-all-2syl.json` 원본에서 `-`로 시작하는 접사류나 띄어쓰기 포함 표제어는 이미 제외되어 있음
(원본 저장소 README 참고).

## 갱신 방법

```sh
npm run build-word-data
```

`scripts/build-word-data.mjs`가 원본을 다시 받아 `words-common-2syl.json`/`words-all-2syl.json` 두
파일을 새로 만든다. `words-extended-2syl.json`은 위 "출처 · 저작권" 절차를 손으로(위 ZIP을 내려받아
CP949로 읽고 가공) 다시 밟아야 한다 — 2002년 조사가 고정 자료라 자동 스크립트로 자주 갱신할 필요가
없어서 별도 npm 스크립트는 아직 안 만들어뒀음.
